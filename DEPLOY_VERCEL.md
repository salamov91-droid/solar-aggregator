# Запуск через Vercel без терминала

Эта версия подготовлена для деплоя через GitHub + Vercel полностью через браузер.

## Что важно

- На Vercel проект может работать **без локального запуска**.
- Каталог может работать в режиме **LIVE_CATALOG_MODE=true** — тогда данные подтягиваются напрямую при запросе к API и не требуют записи на диск.
- Если сайты партнеров временно недоступны, проект показывает встроенные fallback-данные.

## Переменные окружения

Добавьте в Vercel:

- `REFRESH_SECRET` = любое ваше секретное значение
- `LIVE_CATALOG_MODE` = `true`

## Быстрый сценарий деплоя

1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите содержимое папки проекта через кнопку **Add file → Upload files**.
3. Зайдите на vercel.com.
4. Нажмите **Add New → Project**.
5. Импортируйте репозиторий с этим проектом.
6. В разделе Environment Variables добавьте `REFRESH_SECRET` и `LIVE_CATALOG_MODE=true`.
7. Нажмите **Deploy**.

## Что открыть после деплоя

- `/` — главная
- `/catalog` — каталог
- `/calculator` — калькулятор-подборщик
- `/api/solutions` — API каталога
- `/api/recommendation` — API рекомендаций

## Примечание по обновлению данных

На Vercel файловая система не подходит для постоянного хранения кэша. Поэтому проект переключён на live-режим каталога. Это удобно для MVP.

Для production-версии следующего этапа лучше вынести каталог в базу данных или Vercel KV / Supabase.
